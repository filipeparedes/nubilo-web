# utils

Small pure functions with no React in them.

| File         | Role                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `format.ts`  | `baseName` (the last part of a path), `formatSize` (bytes as `18.4 KB`) and `formatDate`.                                  |
| `entries.ts` | `toEntries` joins the folders and files of a folder into one list, folders first, sorted by name, with an optional filter. |
